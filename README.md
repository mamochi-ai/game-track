# 一便でいけます。

絶対に一便で運びたい引っ越し屋が、小さなトラックに過剰な荷物を積んで運ぶ 2D 物理ゲームの Web プロトタイプです。
iPad / iPhone の Safari でタッチだけで遊べます。サーバー不要の静的ファイルだけで動きます。

## 遊び方

1. タイトルで「積み込みをはじめる」。
2. **積む**: 左の一覧から荷物を選び、指で動かして離すと落ちます。赤いときは重なっていて置けません。
   「左／右」で 15° ずつ回転、「置く」でその場に落とす、「戻す」で一覧へ。積んだ荷物に触れると持ち上げられます。
   迷ったら「おすすめの無茶積み」。
3. **固定**: 「ベルト」タブで、光っているフック → 荷物の留めたい場所の順に押します（3 本まで）。張るほど黄 → 橙 → 赤。
4. **出発**: 「一便でいけます。」。右下アクセル、左下ブレーキ（押している間だけ）。
5. 段差・坂・巨大磁石の対向車を越え、旗の間で止まると配達完了。
6. 結果から「同じ積み方でもう一度」または「積み込みに戻って修正」。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html`, `css/`, `js/` | 開発用の分割ソース（静的サーバーでそのまま動く） |
| `dist/index.html` | すべてを 1 ファイルにまとめた配布版（画像・物理エンジン込み） |
| `dist/artifact.html` | claude.ai Artifact 公開用の同内容 |
| `js/config.js` | **調整用パラメータ**（車体・サスペンション・ベルト・磁石・コース・荷物の質量/摩擦/反発/価値/磁石反応・おすすめ配置） |
| `js/physics.js` | Planck.js（Box2D 系）による物理モデル。DOM 非依存 |
| `js/render.js` | Canvas 描画（住宅街・道路・標識・車両・荷物・ベルト・磁力線） |
| `js/main.js` | 画面遷移・タッチ操作・固定時間刻みループ |
| `js/audio.js` | Web Audio による効果音（ユーザー操作後に開始） |
| `assets/sprites/` | 素材シートから切り出した透過 PNG と輪郭データ |
| `js/vendor/planck.min.js` | Planck.js 1.5.1（MIT） |
| `tools/` | 素材切り出し・輪郭生成・ビルド・ヘッドレス物理検証 |

## 開発メモ

```sh
python3 tools/cut_sprites.py assets/source/sheet.png  # 切り出し（クリーム色トラックと磁石トラックは左右反転）
python3 tools/outlines.py                       # 透明部分を除いた輪郭から凸形状の当たり判定を生成
python3 tools/build.py                          # dist/ を再生成
node tools/sim.js all                           # 物理の回帰チェック（積み方・運転・磁石）
```

URL に `?debug` を付けると当たり判定の輪郭を表示します。
