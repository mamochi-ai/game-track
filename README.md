# 一便でいけます。

絶対に一便で運びたい引っ越し屋が、小さなトラックに過剰な荷物を積んで運ぶ 2D 物理ゲームです。
自分で積んだ荷物が、段差・坂・仕掛けをきっかけに物理演算で連鎖して崩れます。
iPad / iPhone の Safari でタッチだけで遊べます。サーバー不要の静的ファイルだけで動きます。

## 遊び方

1. タイトル →「現場をえらぶ」→ ステージを選ぶ（前のステージを配達すると次が解禁）。
2. **積む**: 左の一覧から荷物を選び、指で動かして離すと落ちます。赤いときは重なっていて置けません。
   「左／右」で 15° ずつ回転、「置く」でその場に落とす、「戻す」で一覧へ。積んだ荷物に触れると持ち上げられます。
   迷ったら「おすすめの無茶積み」。
3. **固定**: 「ベルト」タブで、光っているフック → 荷物の留めたい場所の順に押します（3 本まで）。
   同じ荷物をもう一度押すと、扉・腕・折りたたみ部など留める部分が切り替わります。
4. **出発**: 右下アクセル、左下ブレーキ（押している間だけ）。旗の間で止まると配達完了。
5. 結果から「同じ積み方でもう一度」「積み込みに戻って修正」「ステージ選択へ」「次のステージへ」。

## ステージ

| # | 名前 | 仕掛け |
| --- | --- | --- |
| 1 | 近所への引っ越し | 開く冷蔵庫（中にスイカ 3 個）。段差・坂・連続段差 |
| 2 | 親切な商店街 | ソファベッド、動く招き猫、急な坂の頂上、巨大磁石の対向車、親切すぎる作業員 |
| 3 | 本当に一便でいけます？ | 全部盛り＋お掃除ロボット、天地無用の箱、クレーンの「あとひとつだけ！」、下り坂からの停車 |

## 荷物と仕掛け（すべて `js/config.js` で調整）

- 通常: 段ボール（3 サイズ）、タイヤ、長い板、ボウリング球、ゴムボール、キャスター棚。
- 冷蔵庫: 上下の扉はヒンジで本体に接続。強い衝撃か大きな傾きで留め具が外れ、扉が開くと中のスイカが転がり出る。扉の前を荷物で塞ぐか、ベルトで扉を直接留めると開かない。本体は磁石に反応。
- ソファベッド: 衝撃で留め具が外れ、折りたたみ部がヒンジとトルク上限付きモーターで開く。塞がれると止まる。
- 招き猫: 本体と腕を分離。走行中 5 秒周期で腕を振る（直前に鈴と揺れ）。トルクと速度に上限があり、塞ぐと止まる。
- 箱入りお掃除ロボット: 衝撃で箱が開くと起動。接地中だけ有限の力で走り、壁や詰まりで向きを変える。道に落ちたら止まる。
- 天地無用の箱: 逆さのまま約 1 秒続くと上向きの力（上限・速度上限・高さで減衰）。正しい向きに戻ると解除（判定に幅と猶予あり）。
- 巨大磁石の対向車: 背景の別車線を走り、冷蔵庫本体だけを距離に応じた上限付きの力で引く。
- 親切すぎる作業員: 歩道橋から押さえ棒で荷物を押す（力の上限あり）。止まって待つと荷物とサスペンションが沈み、離すと跳ねる。
- あとひとつだけ！: クレーンの下で止まると追加の荷物を降ろす。素通りすれば受け取らない（ボーナス扱い）。

配達価値は荷物と中身（スイカ）を別々の識別子で集計し、重複計上しません。空の冷蔵庫は冷蔵庫として数え、
開いたロボットの空き箱は数えません。進行（解禁・自己ベスト・星）と音設定は端末の localStorage に保存します。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html`, `css/`, `js/` | 開発用の分割ソース（静的サーバーでそのまま動く） |
| `dist/index.html` | すべてを 1 ファイルにまとめた配布版（画像は WebP で内蔵、物理エンジン込み） |
| `dist/artifact.html` | claude.ai Artifact 公開用の同内容 |
| `js/config.js` | 調整用パラメータ（車体、ベルト、磁石、作業員、クレーン、荷物、3 ステージのコース・積荷・おすすめ配置） |
| `js/physics.js` | Planck.js（Box2D 系）による物理モデルと仕掛けの状態。DOM 非依存 |
| `js/render.js` | Canvas 描画（住宅街、道路、標識、歩道橋、クレーン、車両、荷物の部品ごとの描画） |
| `js/main.js` | 画面遷移、タッチ操作、固定時間刻みループ、結果と進行保存 |
| `js/audio.js` | Web Audio による効果音（ユーザー操作後に開始） |
| `assets/source/` | 素材シート（3 枚） |
| `assets/sprites/` | 切り出した透過 PNG と輪郭データ |
| `tools/` | 素材切り出し・輪郭生成・ビルド・ヘッドレス物理検証 |

## 開発メモ

```sh
python3 tools/cut_sprites.py     # 素材シートから切り出し（トラック 2 台は左右反転）
python3 tools/outlines.py        # 透明部分を除いた輪郭から凸形状の当たり判定を生成
python3 tools/build.py           # dist/ を再生成
node tools/sim.js units          # 仕掛けの単体確認（冷蔵庫、ソファ、猫、ロボット、天地無用、磁石、作業員、クレーン）
node tools/sim.js stage 3        # ステージを、踏みっぱなしと減速運転で比較
```

URL に `?debug` を付けると当たり判定の輪郭を表示します。
